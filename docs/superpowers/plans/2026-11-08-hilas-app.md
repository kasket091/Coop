# Hilas Savings App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mobile-first PWA where each Hilas member sees their locked heads, savings, missed months, loan limit and projected December payout. The data comes live from the coop's Google Sheet and every number is computed from the handbook rules.

**Architecture:** A static Vite + React + TypeScript single-page app with no backend.
- `src/rules.ts` holds every money rule as pure, unit-tested functions.
- `src/data.ts` fetches two public sheet ranges as CSV and turns them into `Member[]`.
- `src/App.tsx` renders four bottom tabs.

**Tech Stack:** Vite 5, React 18, TypeScript 5, Vitest 2. Fonts are Google Fonts (Montserrat and Anton). No other runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-08-hilas-app-design.md`

## Global Constraints
- Sheet ID: `19qKH_WibPzvbi2BJ4kK6CgY7D5tke7A88Y0D4BGClbE`. CSV URL is `https://docs.google.com/spreadsheets/d/<ID>/gviz/tq?tqx=out:csv&sheet=<name>&range=<range>`.
- Ranges: `Members Monthly Savings` `A1:R35`; `InterestPaid` `A1:N35`.
- ₱500 per head per month. Cycle is January to December 2026. Contributions are due by the 7th.
- Brand tokens: navy `#1C1B57`, red `#A42A24`, cream `#F2F0E2`, cyan `#09C3E4`, teal `#03989E`, text `#504543`.
- Money is shown as `₱12,345.67` (`en-PH`, 2 decimals). Whole pesos are shown without decimals.
- Runtime dependencies are only `react` and `react-dom`.

## Review Focus
1. **Sheet unreachable or offline:** show "Couldn't load the coop sheet" with a Retry button, never a blank screen (Task 3).
2. **Odd cell values:** blanks, `"6,000"`, `"5,322.48"` and `"-"` are parsed as numbers, with blank or `"-"` read as 0 (Task 2).
3. **Saved member no longer in the sheet:** `localStorage` holds a name that isn't in the list, so the app falls back to the picker (Task 3).
4. **Date outside 2026:** before 2026 nothing counts as missed; after 2026 all 12 months are due (Task 1).
5. **Member missing from InterestPaid:** their interest is 0 and the app doesn't crash (Task 2).

### Task 1: Scaffold + rules engine

**Interfaces (Produces):**
```ts
export type Member = { id: number; name: string; heads: number; paid: number[]; interest: number[] } // paid/interest: 12 entries, Jan..Dec
export const PER_HEAD = 500
export function monthlyDue(heads: number): number                 // heads*500
export function loanLimit(heads: number): number                  // heads*8000
export function minAnnualLoan(heads: number): number              // <=4:10000, <=7:20000, else 30000
export function closedMonths(today: Date): number                 // count of months whose deadline has passed in 2026 (0..12)
export function missedMonths(m: Member, today: Date): number[]    // indexes < closedMonths(today) where paid < monthlyDue
export function missedOwed(amount: number, months: number): number // amount*1.1^months, rounded to centavos
export type CoopSummary = { totalHeads: number; totalSavings: number; totalInterest: number; top: { name: string; interest: number; rebate: number } | null; dividendPerHead: number }
export function coopSummary(members: Member[]): CoopSummary
export type MemberSummary = { monthlyDue: number; saved: number; target: number; missed: number[]; dividend: number; rebate: number; payout: number }
export function memberSummary(m: Member, coop: CoopSummary, today: Date): MemberSummary // payout = target + dividend + rebate
export type RegularQuote = { rate: number; interest: number; installment: number; total: number } | { error: string }
export function regularLoan(capital: number, months: 2 | 3 | 6): RegularQuote
export function monthlyLoan(capital: number, rate: number, months: number): { paidMonthly: number; unpaid: number } // total interest: simple vs compounded
```
